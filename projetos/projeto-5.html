WebApp VitãoTub

Projeto no GitHub

O WebApp VitãoTub é o aplicativo instalável (PWA) do VitãoTub, focado em oferecer a melhor experiência para os fãs do canal.

Recursos do WebApp:

  • Feed de vídeos: Últimos vídeos do canal carregados via RSS.
  • Artigos: Sistema com scroll infinito e modal em tela cheia.
  • Offline: Cache de conteúdo para acesso sem internet.
  • Tradução automática: Suporte para português, inglês e espanhol.
  • Tema escuro/claro: Alternância com persistência de preferência.
  • Swipe to close: Modais fecham com gesto de arraste no celular.
  • Instalável: Pode ser adicionado à tela inicial como um app nativo.

A experiência definitiva do VitãoTub no seu celular.
