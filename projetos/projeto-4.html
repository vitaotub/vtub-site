Site VitãoTub

Projeto no GitHub

O Site VitãoTub é o site oficial do canal, desenvolvido com HTML, CSS e JavaScript puro, sem frameworks ou dependências externas.

Funcionalidades do site:

  • Página principal: Apresentação do canal com estatísticas, vídeos em destaque e redes sociais.
  • Bio: Todos os links oficiais do criador em um só lugar.
  • Feed de vídeos: Últimos vídeos do canal carregados automaticamente via RSS.
  • Sistema de artigos: Artigos exclusivos com scroll infinito e modal de leitura.
  • PWA: Progressive Web App com instalação offline, tema escuro/claro e tradução automática.

Um projeto completo que mostra todo o ecossistema do VitãoTub na web.
